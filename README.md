# K72 Clone - Stunning Animated Website

A beautiful clone of the K72 website featuring stunning animations and modern web design techniques. This project showcases smooth scrolling effects, interactive elements, and eye-catching visual animations.

## ✨ Features

- **Stunning Animations**: Smooth, professional animations throughout the site
- **Responsive Design**: Fully responsive across all device sizes
- **Modern UI/UX**: Clean and contemporary interface design
- **Smooth Scrolling**: Seamless page transitions and scroll-based animations
- **Interactive Elements**: Engaging hover effects and interactive components
- **Optimized Performance**: Fast loading times and smooth animations

## 🚀 Technologies Used

- React Js
- Tailwind CSS (Advanced animations & transitions)
- JavaScript (Vanilla JS for interactions)
- Modern CSS techniques (Flexbox, Grid, Custom Properties)
- GSAP (For Modern & Amazing Animations)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/k72-clone.git
```

2. Navigate to the project directory:
```bash
cd k72-clone
```

3. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js (http-server)
npx http-server
```

4. Visit `http://localhost:8000` in your browser

## 🎯 Key Animation Features

- **Parallax Scrolling**: Dynamic depth and movement on scroll

## 🛠️ Customization

### Changing Colors
Edit the CSS custom properties in `style.css`:
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
  --accent-color: #your-color;
}
```

### Adjusting Animation Speed
Modify animation duration in `animations.css`:
```css
.animated-element {
  animation-duration: 0.6s; /* Adjust as needed */
}
```
